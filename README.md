# 미디어 리터러시 교육 자료실

교육 대상별 서브페이지와 과정별 자료 페이지를 통해 공개 승인된 미디어 리터러시 교육 자료를 제공하는 정적 웹사이트입니다.

## 페이지 구조
- 첫 화면: 교육 대상별 카테고리, 영역 검색, 주요 자료 바로가기
- 학교교육: 초등학교 / 중학교 / 고등학교
- 고등학교: 공통 기본안 / 1·2·3학년 심화안
- 각 과정: 교육과정·운영안 / 차시별 수업지도안 / 학생 활동지 / 평가 루브릭
- 성인 평생교육 / 장애인 미디어 리터러시 / 다문화 미디어 리터러시: 별도 카테고리 서브페이지
- 기준 원본자료 안내: 2022 개정 교육과정 공식 고시, 후속 개정 고시, NCIC 등 공식 확인 경로 및 구조화 데이터 활용 원칙

## 탐색 및 접근성
- 첫 화면에서 교육 영역을 검색할 수 있고, 자주 찾는 고등학교 자료로 바로 이동할 수 있습니다.
- 본문 바로가기(skip link), 키보드 초점 표시, 명확한 링크 스타일을 제공합니다.
- 모바일 화면에 맞춰 카드와 문서 레이아웃이 한 열로 재배치됩니다.
- 사용자의 동작 줄이기 설정을 존중합니다.

## HTML 문서 표준
- `document.html`이 공개 원본 Markdown을 표준 HTML 문서 화면으로 렌더링합니다.
- 공통 스타일은 `assets/archive.css`, 문서 렌더링은 `assets/document.js`에서 관리합니다.
- 공통 요소: 자료실 상단 이동, 경로 표시, 문서 제목, 목차, 본문, 표, 과정 목록 이동.
- 원본 Markdown은 편집·관리용으로 유지하며 웹 열람 시 동일한 HTML 템플릿을 사용합니다.
- 원본 문서가 변경되어도 HTML 문서 화면의 디자인은 별도로 바뀌지 않으며, 동일 템플릿으로 내용을 표시합니다.
- 공통 푸터에는 제안자와 기획·설계 및 구현 지원 정보를 표시합니다.

## 공개 원칙
- 내부 연구 저장소와 분리하여 운영합니다.
- 원자료, 후보 목록, AI 분석, 검토 배치 및 미공개 초안은 복사하지 않습니다.
- 공개 검토를 마친 자료만 연결합니다.
- 장애 접근성과 언어·문화 다양성은 모든 교육 과정에 횡단 적용합니다.
- 고등학교 자료는 2022 개정 교육과정 기반 개발·활용 제안이며 교육부 승인 또는 외부 전문가 검증 완료를 의미하지 않습니다.
