# 미디어 리터러시 교육 자료실

공개 승인된 미디어 리터러시 교육 자료를 제공하기 위한 별도 공개 웹사이트 저장소입니다.

## 공개 원칙
- 내부 연구 저장소 `dangsclub/media-literacy-curriculum-db`와 분리하여 운영합니다.
- 원자료, 후보 목록, AI 분석, 검토 배치 및 미공개 초안은 복사하지 않습니다.
- 자료별 검토와 공개 승인을 마친 최종 산출물만 이 저장소에 추가합니다.
- 공개 자료는 이 저장소의 파일 또는 별도 공개 URL로 연결합니다.

## 홈페이지
- 첫 화면은 교육 아카이브 콘셉트의 반응형 디자인으로 구성합니다.
- 자료 분류 검색과 자료실 공개 원칙을 안내합니다.
- 실제 교육 자료가 승인되기 전까지 분류 항목은 '자료 준비 중'으로 표시합니다.

## 배포 (Render Static Site)
- Repository: `dangsclub/media-literacy-public`
- Branch: `main`
- Build command: 비워 둠
- Publish directory: `.`
